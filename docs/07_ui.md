# 07. Interface

**Status:** Draft | **Última atualização:** 2026-08-03

---

## 7.1 HUD (In-Game)

Elementos sempre visíveis durante `Playing`:
- **Barra de HP do Core** (topo, com número + cor gradiente verde→vermelho).
- **Contador de onda atual** (`Onda 3/10` ou `Onda 7 · Endless`).
- **Pontuação atual** (canto superior direito, animação de incremento).
- **Multiplicador de combo** (canto superior direito, abaixo da pontuação; pulsa e muda cor conforme sobe).
- **Inventário de power-ups ativos/coletados** (barra inferior, ícones com cooldown radial).
- **Indicador de direção de ameaça fora de tela** (seta apontando para Fragments/Rifts fora do FOV da câmera — crítico em AR pois o jogador pode não estar olhando para a ameaça).
- **Botão de pausa** (canto superior esquerdo).
- HUD renderizado em **World Space Canvas** ancorada à câmera (billboard) para não conflitar com o mundo AR, exceto elementos de contexto (barra de Integridade da Rift, que é World Space ancorada à própria Rift).

## 7.2 Menu Principal

- Botão **Jogar** (entra em fluxo de Scanning/Placement ou retoma ambiente salvo).
- Seleção de **Modo de Jogo** (Campanha, Endless, Diário, Zen).
- **Loja** (cosméticos, Battle Pass, moedas).
- **Perfil/Progressão** (nível, upgrades de Orbes).
- **Ranking** (leaderboards).
- **Configurações**.
- Aviso de compatibilidade AR exibido caso o dispositivo não atenda aos requisitos mínimos (`03_ar_system.md` §3.9).

## 7.3 Configurações

- Áudio: volume master, música, SFX (sliders independentes).
- Gráficos: qualidade (Auto/Baixo/Médio/Alto), toggle de partículas reduzidas, toggle de oclusão AR avançada (Depth API on/off para dispositivos capazes).
- Controles: sensibilidade de arraste, inverter assistência de mira (linha de trajetória on/off).
- Conta: vincular Google Play Games / Game Center, restaurar compras.
- Privacidade: consentimento de analytics/ads (LGPD/GDPR compliant, ver `12_analytics.md` e `17_security.md`).
- Acessibilidade: modo de alto contraste para HUD, tamanho de fonte, redução de tremor de câmera/vibração.

## 7.4 Pausa

- Overlay semi-transparente pausa a simulação de física e spawn (não pausa AR tracking, para permitir mover a câmera sem perder tracking).
- Opções: Continuar, Rescan Ambiente, Reiniciar Sessão, Configurações, Sair para Menu.
- Estatísticas parciais da run exibidas (score atual, onda, tempo decorrido).

## 7.5 Game Over

- Tela de resumo: pontuação final, onda alcançada, maior combo, Fragments destruídos, Rifts fechadas.
- Comparativo com melhor resultado pessoal anterior (destaque se novo recorde).
- Recompensas ganhas (moeda, XP, progresso de desafio diário/Battle Pass) com animação de "reveal".
- CTAs: Tentar Novamente, Ver Ranking, Compartilhar (gera clipe/imagem para redes sociais), Reviver (oferta de anúncio recompensado/Cristais — ver `10_monetization.md`), Voltar ao Menu.

## 7.6 Ranking

- Abas: **Global**, **Amigos** (via Google Play Games Friends), **Desafio Diário**.
- Filtros por Modo de Jogo (Campanha/Endless/Diário).
- Exibição de posição do jogador destacada mesmo fora do top visível (scroll automático até sua posição, com contexto de ±3 posições).
- Cache local de ranking com sincronização periódica (ver `11_backend.md`) para funcionar offline com dados levemente desatualizados.
